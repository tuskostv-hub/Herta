# types.md — Система типов языка Herta

---

## 1. Общие принципы

Система типов языка Herta основана на трёх ключевых принципах:

- **Номинальная типизация** — два типа совместимы только если их имена совпадают.
  Структурное сходство не является основанием для совместимости.
- **Ограниченные неявные приведения** — допускаются только **расширяющие** (widening)
  численные приведения, а также адаптация нетипизированных литералов к контексту.
  Сужающие и семантически опасные преобразования требуют явного cast'а `T(expr)`.
  Полная таблица — §5.4.
- **Value semantics** — все значения передаются и присваиваются по значению
  (копированием). Ссылочных типов нет.

Проверка типов производится **статически** на этапе компиляции.
Типовые ошибки не могут возникнуть во время выполнения программы.

## 2. Встроенные типы

### 2.1 Целочисленные типы со знаком

| Тип     | Размер  | Диапазон значений                                      |
|---------|---------|--------------------------------------------------------|
| `int8`  | 8 бит   | −128 .. 127                                            |
| `int16` | 16 бит  | −32 768 .. 32 767                                      |
| `int32` | 32 бита | −2 147 483 648 .. 2 147 483 647                        |
| `int64` | 64 бита | −9 223 372 036 854 775 808 .. 9 223 372 036 854 775 807|

### 2.2 Целочисленные типы без знака

| Тип      | Размер  | Диапазон значений          |
|----------|---------|----------------------------|
| `uint8`  | 8 бит   | 0 .. 255                   |
| `uint16` | 16 бит  | 0 .. 65 535                |
| `uint32` | 32 бита | 0 .. 4 294 967 295         |
| `uint64` | 64 бита | 0 .. 18 446 744 073 709 551 615 |

### 2.3 Вещественные типы

| Тип       | Размер  | Стандарт    | Точность            |
|-----------|---------|-------------|---------------------|
| `float32` | 32 бита | IEEE 754    | ~7 значимых цифр    |
| `float64` | 64 бита | IEEE 754    | ~15 значимых цифр   |

### 2.4 Булев тип

| Тип    | Размер  | Значения        |
|--------|---------|-----------------|
| `bool` | 1 байт  | `true`, `false` |

`bool` не совместим с числовыми типами. Приведение `bool` ↔ `int` запрещено.

### 2.4.5 Символьный тип `char`

| Тип    | Размер  | Описание                            |
|--------|---------|-------------------------------------|
| `char` | 32 бита | один Unicode code point (или ASCII) |

- **Не является арифметическим типом.** Операторы `+`/`-`/`*`/`/`/`%`,
  а также `<`/`>`/`<=`/`>=` для `char` **не определены**.
- Допустимы только `==` и `!=` (результат `bool`).
- Допустимо явное приведение `char ↔ intN/uintN` — для получения числового
  кода символа и обратного создания.
- Литералы: `'a'`, `'\n'`, `'\t'`, `'\r'`, `'\\'`, `'\''`, `'\0'`.
- Многобайтные символы (Unicode сверх ASCII) в литералах в v1 не поддерживаются.

### 2.5 Строковый тип

| Тип      | Кодировка | Описание                                 |
|----------|-----------|------------------------------------------|
| `string` | UTF-8     | Неизменяемая последовательность байт.    |

Строка хранится как пара (указатель на данные, длина в байтах).
Прямой доступ по индексу к символам не поддерживается.
Встроенная функция `len(s)` возвращает длину строки в **байтах** (`int32`).

Допустимые операции над `string`:

| Операция       | Оператор / функция | Тип результата |
|----------------|--------------------|----------------|
| Конкатенация   | `s1 + s2`          | `string`       |
| Длина в байтах | `len(s)`           | `int32`        |
| Равенство      | `s1 == s2`         | `bool`         |
| Неравенство    | `s1 != s2`         | `bool`         |

### 2.6 Тип `void`

`void` — тип отсутствия значения. Используется исключительно как тип возврата функции.
Переменная типа `void` объявлена быть не может.

```
fn greet(name: string) void {
    print("Hello, " + name);
}
```

## 3. Составные типы

### 3.1 Массивы

Массив — фиксированная последовательность элементов одного типа.
**Размер является частью типа** и известен на этапе компиляции.

```
[T; N]
```

- `T` — тип элемента (любой тип, кроме `void`)
- `N` — неотрицательный целочисленный литерал

Примеры:

```
[int32; 5]       // массив из 5 элементов int32
[float64; 3]     // массив из 3 элементов float64
[bool; 10]       // массив из 10 элементов bool
[[int32; 4]; 3]  // массив из 3 массивов по 4 элемента int32
```

#### Операции над массивами

| Операция             | Синтаксис    | Тип результата | Примечание                      |
|----------------------|--------------|----------------|---------------------------------|
| Чтение по индексу    | `arr[i]`     | `T`            | runtime error при выходе за границы |
| Запись по индексу    | `arr[i] = v` | —              | только для `var`-переменных     |
| Длина                | `len(arr)`   | `int32`        | компилируется в константу типа  |
| Равенство            | `arr == b`   | `bool`         | поэлементное, одинаковые типы и размер |
| Неравенство          | `arr != b`   | `bool`         | то же                           |

Индекс `i` должен быть целочисленного типа.

Массивы разных размеров — **разные типы**:

```
[int32; 3] != [int32; 5]   // несовместимые типы
```

Инициализация массива:

```
let a: [int32; 3] = [1, 2, 3];
var b: [float64; 2] = [0.0, 0.0];
```

Количество элементов в литерале должно точно совпадать с размером типа.

### 3.2 Структуры

Структура — именованный составной тип с фиксированным набором полей.

```
struct ИмяСтруктуры {
    поле1: Тип1,
    поле2: Тип2,
}
```

Порядок полей в объявлении фиксирован. Два поля с одинаковым именем в одной
структуре запрещены.

Пример:

```
struct Vec2 {
    x: float64,
    y: float64,
}

struct Rect {
    origin: Vec2,
    width:  float64,
    height: float64,
}
```

#### Инициализация структуры

```
let v: Vec2 = Vec2 { x: 1.0, y: 2.0 };
```

Все поля структуры **обязаны** быть указаны в литерале.
Порядок полей в литерале должен совпадать с порядком объявления.

#### Доступ к полям

```
v.x         // чтение поля
v.x = 3.0   // запись поля (только для var)
```

#### Вложенные структуры

```
let r: Rect = Rect {
    origin: Vec2 { x: 0.0, y: 0.0 },
    width:  100.0,
    height: 50.0,
};

let ox: float64 = r.origin.x;
```

#### Совместимость структур

Две структуры совместимы только при совпадении имён (номинальная типизация):

```
struct A { x: int32, }
struct B { x: int32, }

var a: A = A { x: 1 };
var b: B = a;   // ОШИБКА: A и B — разные типы, несмотря на одинаковые поля
```

## 4. Синонимы типов

Синоним (`type alias`) — альтернативное имя для существующего типа.
Синоним **не создаёт новый тип**: значения синонима и базового типа
полностью совместимы без приведения.

```
type ИмяСинонима = СуществующийТип ;
```

Примеры:

```
type Meters    = int32;
type Seconds   = float64;
type Matrix4x4 = [[float64; 4]; 4];
type Name      = string;
```

Использование:

```
type Meters = int32;

fn travel(dist: Meters, time: Seconds) float64 {
    return float64(dist) / time;
}

var d: Meters  = 100;
var t: Seconds = 2.5;
let speed := travel(d, t);
```

Синонимы допускаются на верхнем уровне и внутри пространств имён.

## 5. Правила приведения типов

Явное приведение: `T(expr)`.

### 5.1 Таблица допустимых приведений

| Из            | В                              | Тип операции             | Поведение при потере данных |
|---------------|--------------------------------|--------------------------|-----------------------------|
| `intN`        | `intM` (M > N)                 | widening (расширение)    | знак расширяется            |
| `intN`        | `intM` (M < N)                 | narrowing (сужение)      | старшие биты отбрасываются  |
| `intN`        | `uintM`                        | знаковое → беззнаковое   | битовое представление сохраняется |
| `uintN`       | `uintM` (M > N)                | widening                 | нулевое расширение          |
| `uintN`       | `uintM` (M < N)                | narrowing                | старшие биты отбрасываются  |
| `uintN`       | `intM`                         | беззнаковое → знаковое   | битовое представление сохраняется |
| `intN`/`uintN`| `float32`, `float64`           | целое → вещественное     | возможна потеря точности для больших int64 |
| `float32`     | `float64`                      | widening                 | точное                      |
| `float64`     | `float32`                      | narrowing                | возможна потеря точности    |
| `floatN`      | `intN`/`uintN`                 | вещественное → целое     | дробная часть усекается (к нулю) |

### 5.2 Запрещённые приведения

Следующие приведения являются **ошибкой компиляции** даже при явном cast'е:

| Из         | В                | Причина                          |
|------------|------------------|----------------------------------|
| `bool`     | любой числовой   | bool не является числом          |
| числовой   | `bool`           | bool не является числом          |
| `string`   | числовой         | нет определённого преобразования |
| числовой   | `string`         | нет определённого преобразования |
| `struct`   | любой            | структуры не приводятся          |
| `[T; N]`   | любой            | массивы не приводятся            |

### 5.3 Примеры приведений

```
var i: int32   = 1000;
var b: int8    = int8(i);       // narrowing: 1000 % 256 = 232 (как uint), как int8 = -24
var u: uint32  = uint32(i);     // widening: 1000
var f: float64 = float64(i);    // 1000.0
var t: int32   = int32(3.99);   // усечение: 3

let x: int64 = int64(uint32(4294967295));  // цепочка приведений: uint32_max → int64
```

### 5.4 Неявные приведения

Тип `A` называется **неявно приводимым** к типу `B` (запись: `A ⇝ B`), если
выполняется одно из условий:

1. `A == B` (тождественное приведение).
2. `A = intN`, `B = intM`, `N < M` — знаковое расширение.
3. `A = uintN`, `B = uintM`, `N < M` — расширение нулём.
4. `A = uintN`, `B = intM`, `N < M` — беззнаковое всегда помещается в более широкое знаковое.
5. `A` — любой целочисленный тип (`intN`/`uintN`), `B = float64` — преобразование
   в вещественное; для 64-битных целых возможна потеря точности.
6. `A = intN` или `uintN` с `N ≤ 16`, `B = float32` — точное преобразование.
7. `A = float32`, `B = float64` — точное расширение.

Все остальные приведения требуют явного cast'а `T(expr)` (либо запрещены — см. §5.2).

#### Где применяется неявное приведение

| Контекст                            | Правило |
|-------------------------------------|---------|
| Инициализация переменной `T x = e`  | тип `e` должен быть `⇝ T` |
| Присваивание `lvalue = e`           | тип `e` должен быть `⇝ type(lvalue)` |
| Аргумент функции / метода           | тип аргумента должен быть `⇝ тип параметра` |
| `return e` в функции с типом `T`    | тип `e` должен быть `⇝ T` |
| Бинарная арифметика `a OP b`        | если `type(a) ⇝ type(b)` — `a` приводится к `type(b)`; симметрично; если ни одно из направлений не работает — ошибка |
| Сравнения `a == b`, `a < b` и т.п.  | то же правило, что для арифметики; результат — `bool` |
| Условие `if`/`while`                | тип — строго `bool`, неявные приведения **не** применяются |

#### Запрещённые неявные приведения

Все следующие требуют явного cast'а (или вовсе запрещены — см. §5.2):

- Любое сужение: `intM → intN` при `M > N`, `float64 → float32` и т.п.
- `intN → uintM` (любые N, M) — потеря знакового бита может изменить значение.
- `floatN → intN`/`uintN` — усечение дробной части.
- Смешанные signed/unsigned одинаковой ширины: `int32 ↔ uint32`.

#### Примеры

```
var a: int32 = 5;
var b: int64 = a;             // OK: int32 ⇝ int64
var f: float64 = a;           // OK: int32 ⇝ float64
var s: int16 = a;             // ОШИБКА: сужение, нужно int16(a)
var u: uint32 = a;            // ОШИБКА: signed → unsigned, нужно uint32(a)

let p := a + 1.5;             // 1.5 — нетипизированный float-литерал;
                              // но a — int32, общий тип не выводится
                              // (int32 не ⇝ float-литерал, см. §6) — ОШИБКА
let q := float64(a) + 1.5;    // OK: q = float64
```

## 6. Числовые литералы и вывод их типов

По умолчанию числовые литералы получают следующие типы:

| Литерал            | Тип по умолчанию |
|--------------------|------------------|
| `42`, `0xFF`       | `int32`          |
| `3.14`, `1.5e10`   | `float64`        |
| `true`, `false`    | `bool`           |
| `"hello"`          | `string`         |

При наличии явного типа в объявлении литерал проверяется на совместимость:

```
let x: int8  = 42;     // OK: 42 помещается в int8
let y: int8  = 200;    // ОШИБКА: 200 не помещается в int8 (−128..127)
let z: float32 = 1.0;  // OK
```

При выводе типа (`:=`) применяется тип по умолчанию:

```
var a := 42;    // a: int32
var b := 3.14;  // b: float64
var c := true;  // c: bool
```

## 7. Совместимость типов в операциях

Бинарные операции (`+`, `-`, `*`, `/`, `%`, `==`, `!=`, `<`, `>`, `<=`, `>=`)
требуют, чтобы оба операнда имели **одинаковый тип** **после применения
неявных приведений** по правилам §5.4. Если ни один операнд не может быть
приведён к типу другого без потерь — **ошибка компиляции**.

```
var a: int32  = 1;
var b: int64  = 2;
var c := a + b;          // OK: int32 ⇝ int64, тип c = int64
var d := int32(b) + a;   // OK: явное приведение работает тоже, тип d = int32

var u: uint32 = 1;
var s: int32  = u + a;   // ОШИБКА: uint32 и int32 не ⇝ друг к другу
                         //   (нужен явный cast)
```

## 8. Размещение типов в памяти

Данный раздел описывает представление значений на платформе x86-64.

| Тип       | Размер в памяти | Выравнивание |
|-----------|-----------------|--------------|
| `int8`    | 1 байт          | 1 байт       |
| `int16`   | 2 байта         | 2 байта      |
| `int32`   | 4 байта         | 4 байта      |
| `int64`   | 8 байт          | 8 байт       |
| `uint8`   | 1 байт          | 1 байт       |
| `uint16`  | 2 байта         | 2 байта      |
| `uint32`  | 4 байта         | 4 байта      |
| `uint64`  | 8 байт          | 8 байт       |
| `float32` | 4 байта         | 4 байта      |
| `float64` | 8 байт          | 8 байт       |
| `bool`    | 1 байт          | 1 байт       |
| `string`  | 16 байт         | 8 байт       |
| `[T; N]`  | sizeof(T) × N   | align(T)     |
| `struct`  | сумма полей + padding | max(align полей) |

Поля структуры размещаются последовательно с выравниванием. Между полями
компилятор вставляет **padding** для соблюдения выравнивания каждого поля.

Пример:

```
struct Example {
    a: int8,     // offset 0, size 1
                 // padding 3 байта
    b: int32,    // offset 4, size 4
    c: int16,    // offset 8, size 2
                 // padding 6 байт
    d: float64,  // offset 16, size 8
}
// итого: 24 байта
```

## 9. Таблица типов: сводка

| Тип           | Категория       | Размер    | Значения по умолчанию литерала |
|---------------|-----------------|-----------|-------------------------------|
| `int8`        | целое, знаковое | 8 бит     | —                             |
| `int16`       | целое, знаковое | 16 бит    | —                             |
| `int32`       | целое, знаковое | 32 бита   | целый литерал (`42`)          |
| `int64`       | целое, знаковое | 64 бита   | —                             |
| `uint8`       | целое, б/з      | 8 бит     | —                             |
| `uint16`      | целое, б/з      | 16 бит    | —                             |
| `uint32`      | целое, б/з      | 32 бита   | —                             |
| `uint64`      | целое, б/з      | 64 бита   | —                             |
| `float32`     | вещественное    | 32 бита   | —                             |
| `float64`     | вещественное    | 64 бита   | вещественный литерал (`3.14`) |
| `bool`        | булев           | 1 байт    | `true` / `false`              |
| `string`      | строковый       | 16 байт   | строковый литерал (`"..."`)   |
| `void`        | служебный       | —         | —                             |
| `[T; N]`      | массив          | sizeof(T)×N | литерал массива `[...]`     |
| `struct { }` | структура       | sum+pad   | литерал структуры `S { }`    |
